# Eastern Catholic Church Website Project

This project is dedicated to documenting the Eastern Catholic Church and its rich heritage.

## Features
- Comprehensive information on various Eastern Catholic Churches.
- User-friendly interface for visitors to explore resources.
- HTML5 standards compliant.

## How to Use
1. Clone the repository using `git clone <repository-url>`.
2. Navigate to the project directory.
3. Open `index.html` in your favorite browser to explore the website.
